# Clavier en jeu

Jeu d’entraînement à la frappe au clavier : 50 phrases en mode Classique (majuscules, chiffres, accents, caractères spéciaux), 50 phrases très simples en mode Allophone, score sur 100, temps, erreurs, effacements et touches difficiles. Tutos pour @, accents, tréma, majuscules accentuées.

Un seul fichier `index.html` (sans CDN, sans traceur), installable (PWA), fonctionne hors ligne. Les scores restent sur l’appareil.

À chaque mise à jour : changer `VERSION` dans `sw.js` et la version affichée dans « À propos ».

Conçu par Tom Rougeaud, avec l’aide de l’IA Claude Sonnet 5.5 (Anthropic). CC BY-NC 4.0.
